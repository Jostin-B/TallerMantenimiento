# TallerMantenimiento

Proyecto realizado para la asignatura Programación III del ITLA.

Es una aplicación de consola desarrollada en C# y .NET para gestionar los clientes de un taller de mantenimiento de vehículos.

## Funcionalidades

- Registrar clientes.
- Consultar clientes registrados.
- Actualizar información de clientes.
- Eliminar clientes.
- Seleccionar servicios de mantenimiento.
- Guardar los datos en un archivo JSON.

## Cómo ejecutar el proyecto

Es necesario tener instalado el SDK de .NET.

Desde la carpeta del proyecto, ejecutar:

``` dotnet run ```

## Git Flow

Para el desarrollo se utilizaron las ramas `main`, `develop` y `qa`, además de cinco ramas `feature/` para implementar las funcionalidades.
